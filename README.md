## About

<br />

I am an Electrical &amp; Electronics Engineering undergraduate who enjoys understanding how power moves — from generation through transmission, protection, and into the machines and systems that depend on it.

My work sits at the intersection of six areas:

<br />

| | |
|:--|:--|
| **Power Systems** | Analysis of generation, transmission, and distribution networks |
| **Electrical Design** | Schematic design and layout using industry-standard CAD tools |
| **Protection Engineering** | Relay coordination, fault analysis, and system reliability |
| **Embedded Systems** | ESP32-based automation and real-time monitoring |
| **Industrial Automation** | Control systems for manufacturing and process environments |
| **Renewable Energy &amp; Electric Mobility** | Grid integration and the systems powering the energy transition |

<br />

I care about building systems that are safe, efficient, and built to last — and about the discipline that separates a working circuit from a reliable one.
